# La Ioachim

Concept de site din șablonul restaurant cu comenzi. [Previzualizare](https://cojocariuemilian73.github.io/la-ioachim-falticeni/) · [Meniu pentru telefon](https://cojocariuemilian73.github.io/la-ioachim-falticeni/meniu.html) · [QR pentru masă](https://cojocariuemilian73.github.io/la-ioachim-falticeni/print/card-masa.html).

Site de prezentare neoficial, marcat `noindex`. Telefonul public al restaurantului este +40 791 201 308. Datele și fotografiile se confirmă cu localul înainte de folosire ca site oficial.

## Actualizare

Editează `sursa/date-site.json`, apoi rulează `python sursa/genereaza.py`. Pentru fotografii noi rulează întâi `python sursa/optimizeaza_imagini.py`. Dacă schimbi domeniul, rulează `python sursa/qr.py`, apoi regenerează paginile. Scripturile de imagine și QR folosesc Pillow și Segno.
